# Maven Fuzzy Factory Analysis — Excel Project

## Project Overview
This project analyzes e-commerce business performance using Microsoft Excel, Power Pivot, and data modeling. The goal is to transform raw business data into meaningful insights about website sessions, orders, revenue, products, and marketing performance.

## Tools & Techniques
- Microsoft Excel
- Power Pivot and Data Model
- Relationships between multiple datasets
- PivotTables and PivotCharts
- Interactive slicers
- KPI analysis and dashboard visualization

## Project Features
- Website traffic and session analysis
- Order and revenue performance
- Average order value analysis
- Marketing campaign performance
- Product and business performance analysis
- Interactive dashboard with slicers

## Workflow
1. Imported and organized multiple datasets.
2. Created relationships between tables using the Data Model.
3. Developed PivotTables to analyze key business metrics.
4. Built charts and interactive slicers.
5. Designed a dashboard to communicate business performance.

## Key Learning Outcomes
- Data modeling and relationship management
- Business KPI analysis
- Interactive Excel dashboard development
- Translating data into actionable business insights
